DOM to PDF Picker

Printing settings for the selected page element. Every printout is a single continuous "long page" PDF - there is no page splitting.

Page margins
Used in the @page rule for both print modes.
Print mode
Mode A marks the selected element and its ancestors with attributes, injects a @media print stylesheet and prints the current page. Mode B deep-clones the element into a hidden frame with computed styles rewritten inline, then prints only that frame - useful when a page has aggressive CSS that is hard to override. You can also switch mode for a single pick with the M key on the picker badge.
Print content
This sets a CSS property, but background colors/images will only actually appear in the PDF if you also enable "Background graphics" in the browser's native print dialog. See the README.
